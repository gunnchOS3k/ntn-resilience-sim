# Reproducibility — NTN Resilience Simulator (RQ3) This repository produces **synthetic disruption/fallback timelines** under documented assumptions (3GPP TR 38.821 ranges plus configured/synthetic entries). It does **not** report operator performance and does **not** claim University of Oulu affiliation. ## Clone / setup / run ```bash git clone https://github.com/gunnchOS3k/ntn-resilience-sim.git cd ntn-resilience-sim python3 -m venv .venv source .venv/bin/activate # Windows: .venv\Scripts\activate pip install -r requirements.txt make test make smoke # long e2e; synthetic only make reproduce ``` Canonical independent digital path: `make reproduce` → `scripts/reproduce.py` → `results/experim
